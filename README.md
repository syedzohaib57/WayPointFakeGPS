# 📍 WayPointFakeGPS

### Change Your Location. Explore Without Limits.

**WayPointFakeGPS** is a modern Android GPS location simulation application that allows users to change their virtual location, simulate GPS coordinates, and explore different places around the world.

Built with a clean, intuitive interface, WayPointFakeGPS makes location simulation simple, precise, and accessible.

## ✨ Features

- 📍 **Fake GPS Location** – Simulate your device's GPS position.

- 🎯 **Precise Coordinates** – Set custom latitude and longitude values.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Android device or emulator
- Developer Options enabled
- Mock location support

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/syedzohaib57/WayPointFakeGPS.git
```

**2. Open the project**

Open Android Studio and select the cloned project directory.

**3. Sync dependencies**

Allow Gradle to download and synchronize the required dependencies.

**4. Build and run**

Connect an Android device or start an emulator, then build and install the application.

## ⚙️ Enable Mock Location

To simulate GPS locations on supported Android devices:

1. Open your device's **Settings**.
2. Navigate to **About Phone**.
3. Tap **Build Number** seven times to enable Developer Options, if not already enabled.
4. Open **Developer Options**.
5. Find **Select Mock Location App**.
6. Select **WayPointFakeGPS**.
7. Launch the application and select your desired location.

**Note:** Menu names may vary depending on the Android version and device manufacturer.
